# 3.1 Product Discovery

# NoteWise – Personalized Learning System from Lecture Materials

## Problem
Students often have many digital lecture materials but turning them into an effective learning process is still largely manual. They must read long documents, identify important concepts, create notes, prepare practice questions, and decide what to study next.

Generic AI assistants can summarize or answer questions, but they may not connect the student's own materials with practice results and learning progress.

## Target Users
- University students.
- Independent learners.
- Students preparing for examinations.

## User Needs
- Upload and manage lecture materials.
- Organize and access learning documents.
- Understand important concepts more quickly.
- Ask questions based on selected materials.
- Practice through quizzes.
- Review learning results.
- Identify topics requiring more attention.
- Receive personalized suggestions for the next learning action.

## Product Opportunity
```text
Learning Materials → Document Processing → Summary / Q&A / Quiz
→ Practice → Quiz Results → Performance Analysis
→ Weak-topic Identification → Personalized Recommendation
→ Further Learning
```

## Product Value
NoteWise transforms passive lecture materials into structured learning resources. It combines document-based learning activities with learning evidence so students can understand their current performance and choose appropriate next actions.

## Core Learning Journey
```text
Upload Material → Process Material → Study with Summary or Q&A
→ Generate Quiz → Complete Quiz → Review Results
→ Analyze Performance → Identify Weak Topics
→ Receive Recommendation → Continue Learning
```

## Product Goal
Enable students to transform their own lecture materials into personalized learning activities and evidence-based next study actions.

## Current Product Boundary
The current NoteWise scope focuses on:
- Learning document management.
- Document processing.
- AI-assisted summarization.
- Document-based question answering.
- Quiz generation.
- Quiz completion and evaluation.
- Learning performance analysis.
- Weak-topic identification.
- Personalized learning recommendations.
- Learning history.

Features outside the approved scope must not be added automatically.
